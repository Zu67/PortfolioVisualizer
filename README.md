# PortfolioVisualizer

Python scripts for positions built from a brokerage export and for prices from Yahoo Finance. The exports themselves are not in this repository. `.vscode/settings.json` sets only `files.autoSave` to `afterDelay`. It does not set `files.autoSaveDelay`. `.gitattributes` is the one line `* text=auto`, under the comment "Auto detect text files and perform LF normalization".
