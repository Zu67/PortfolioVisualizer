# PortfolioVisualizer

This branch is `DevelopmentPortfolioVisualizer`. The commits that added the scripts run from 2024-04-30 ("Initial commit") through 2024-05-13 ("Updating PortfolioVisualizer"). Later commits moved those files into `scripts/` and updated this README.

| File | What it does |
| --- | --- |
| `scripts/Data Generator.py` | Uses Faker to write 100 rows to a local `transactiondata.csv`. Each row is a date, a four-letter symbol, buy or sell, a fake person's name in the broker column, a quantity from 1 to 100, and a price from 10.00 to 500.00. |
| `scripts/PortfolioData` | Reads a local `PortfolioData.csv` and plots the running sum of daily percent changes. The chart title is "Portfolio Performance". |
| `scripts/PortfolioVisualizerInGit.py` | Prints two downloads of the last 300 calendar days of VTI and SPY, then stops. A third copy of that download is not reached. See below. |

`scripts/PortfolioVisualizerInGit.py` prints two downloads of VTI and SPY. Each window is `datetime.now()` minus 300 days through `datetime.now()`. The same block is pasted a third time after the `df` loop, and that copy does not run. The next loop reads `df`, which this file has not assigned, so running it from the top stops there. The lines after that are not reached. The loop calls `df.items()` and unpacks each key as `(universe_symbol, time)`, so `df` has to be a mapping of those pairs, not a table. `constituents_df` is the table built from that mapping. The next filter walks that table as if each item had `HasFundamentalData`. Iterating a DataFrame yields column names, so that filter would fail even after `df` was assigned. The lines after that build Morningstar-style super-sector, sector, and industry lookup tables, and plot sector and super-sector weights. Those pie charts select `2024-03-26` and the titles say `2023-03-26`. The last cells use `df_security`, `df_benchmark`, `selected_symbol`, and `selected_benchmark`, which are also not defined here. The daily risk-free rate is `(1.05) ** (1/252) - 1`. Beta is the covariance of the two raw return series divided by the variance of the benchmark. Sharpe is that day's excess return divided by the 30-day rolling standard deviation of excess returns. Treynor is the 30-day mean of excess return, times 252, divided by beta. Jensen's alpha is the 30-day mean of return minus the expected daily return, times 252. The chart title is "Rolling Investment Metrics" even though the Sharpe numerator is one day. The last chart title is "Price Comparison", and the series is cumulative percent return, labeled with `selected_symbol.Value` and `selected_benchmark.Value`. The super-sector line chart's legend title is "Industry".

The default branch, `main`, also has the holding-cost scripts and `data/ETF Constituent Data - Examples.csv`.
