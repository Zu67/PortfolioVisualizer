# PortfolioVisualizer

This branch is `DevelopmentPortfolioVisualizer`. The commits on it run from 2024-04-30 ("Initial commit") through 2024-05-13 ("Updating PortfolioVisualizer").

| File | What it does |
| --- | --- |
| `scripts/Data Generator.py` | Uses Faker to write 100 synthetic buy and sell rows to a local `transactiondata.csv`. |
| `scripts/PortfolioData` | Plots cumulative returns from a local `PortfolioData.csv`. |
| `scripts/PortfolioVisualizerInGit.py` | Downloads about 300 days of VTI and SPY. |

The default branch, `main`, also has the holding-cost scripts and `data/ETF Constituent Data - Examples.csv`.
